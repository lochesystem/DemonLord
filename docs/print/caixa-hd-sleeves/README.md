# Caixa DemonLord - 76 cartas

Gabarito de uma tuck box dimensionada para o baralho de alta fidelidade.

## Especificação adotada

- Dimensão interna: 69 x 45 x 94 mm
- Cartas: Poker, 63,5 x 88,9 mm
- Capacidade: 76 cartas com sleeves simples de até 66 x 91 mm
- Material sugerido: cartão branco 350 g, aproximadamente 0,5 mm
- Sangria: 3 mm
- Espaçador removível montado: 67 x 18 x 92 mm

## Arquivos

- `dieline-caixa-76-cartas-sleeves.svg`: caixa principal, vetorial e em escala 1:1
- `dieline-espacador-sem-sleeves.svg`: espaçador para usar o baralho sem sleeves
- PDF A3: `demonlord-caixa-76-cartas-sleeves-dieline.pdf`

## Cores técnicas

- Azul: corte
- Vermelho tracejado: vinco
- Verde tracejado: limite de sangria
- Dourado tracejado: área segura

O modelo deve ser validado pela gráfica antes da produção, especialmente quanto
à compensação de dobra, espessura efetiva do papel e desenho final da faca.
